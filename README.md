# CONSTELAÇÃO PRESERA — protótipo navegável

Website estático em português de Portugal, responsivo, sem dependências nem contas fictícias.

## Pré-visualização

Abrir `index.html` no navegador. Para servir localmente, executar `python3 -m http.server 8000` nesta pasta e visitar `http://localhost:8000`.

## Publicação futura em Cloudflare Pages

Ligar o repositório GitHub a um novo projeto Pages; selecionar a branch `main`, framework `None`, comando de build vazio e diretório de saída `/` (raiz). **A ligação ao Pages publica uma versão acessível pela internet: só a efetuar depois de aprovada a pré-visualização.**

## Estado

Protótipo visual e navegável. As secções assinaladas «Em construção» não têm ainda serviços de autenticação, pagamento, cursos ou inscrições. Fotografias reais e conteúdos definitivos serão integrados posteriormente.
